# Privacy

DK Habit Tracker v0.1 is local-first.

- No account is required.
- No INTERNET permission is requested.
- No analytics, advertising, crash-reporting or tracking SDK is included.
- Habit data is stored in the app's private local Android storage.
- Data leaves the app only when the user explicitly exports a JSON backup through Android's system document picker.
- Reminder notifications are generated locally on the device.
